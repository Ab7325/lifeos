LifeOS Health: privacy

LifeOS Health is a personal tool made and used by one person (Rishabh Sharma). It is not offered to the public. This page says what it does with Google Health data.

What it reads

With the owner's permission, it reads the owner's own Google Health data, read-only: activity and fitness (steps, distance, calories), health metrics and measurements (such as weight), and sleep. It cannot change anything in Google Health.

What it does with it

A script on the owner's own computer reads the data once or twice a day and saves daily totals (steps, sleep length, a sleep score worked out from it) to the owner's own private database, where the owner's habit tracker and game read them. The data is used only to show the owner their own progress and to run that game.

What it does not do

  • It does not sell, share or transfer the data to anyone.
  • It does not use the data for advertising, or to build profiles for anyone.
  • No person reads the data except the owner.

Google API Services User Data Policy

LifeOS Health's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions, and can delete the saved data from the database.
